Conectar ao GitHub

As listas ficam guardadas num arquivo dentro de um repositório do GitHub. Preencha os dados abaixo pra conectar — cada pessoa faz isso uma vez no próprio navegador.

Como criar o token?
  1. No GitHub, vá em Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Em "Repository access", escolha "Only select repositories" e selecione este repositório.
  3. Em "Permissions", dê acesso de leitura e escrita a "Contents".
  4. Gere o token e cole ele aqui. Guarde-o em local seguro — ele não aparece de novo depois.
